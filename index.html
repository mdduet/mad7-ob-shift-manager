▸ What format does the CSV need?
Any of these column layouts work:
login, skill_name — simplest format
login, shift, skill1, skill2, ... — multi-skill per row
Login, Shift, Training Count, All Trainings — QuickSight format

How to get this from QuickSight:
1. Open the OB Skill Matrix dashboard
2. Find the data table → click the ⋮ menu → Export to CSV
3. Drop the downloaded file here

Or from any spreadsheet: Export as CSV with login in first column, skills in other columns.
