# MAD7 OB Shift Manager

A comprehensive workforce management tool for Amazon OB facilities. Built with vanilla JavaScript, HTML5, and CSS3.

## Features

- **Real-time Floor Map** — Visualize live station capacity and worker assignments
- **HC Planning** — Manage headcount targets across processes
- **Rate Management** — Track hourly productivity rates per process
- **Skills Matrix** — Monitor worker certifications and training progress
- **Alerts & Monitoring** — Get real-time notifications on compliance and issues
- **IT Ticket System** — Track and manage facility issues
- **Historical Analysis** — Review past performance data

## Getting Started

1. Open `index.html` in your web browser
2. Navigate using the top navigation tabs
3. Your data persists locally in browser storage
